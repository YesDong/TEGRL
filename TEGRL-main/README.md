# TEGRL Core Code

This directory contains instructions for reproducing the results presented in our work.

Run the code directly from PyCharm.

## Datasets

The datasets for cross-graph node classification are located in the Datasets directory, while the datasets for traditional node classification can be downloaded directly via the code.

After selecting the dataset in the code, you can run it directly to reproduce the results.
